Avatour – Telepresence Robotics Platform

  • Technologies Used: C++, ROS, Verilog, HTML, JavaScript, SQL, PHP, AWS
  • Institution: Imperial College London
  • Project date: 2023 – 2024
  • Type: Group Engineering Project

Project Details

Avatour is a telepresence robotics platform that enables a remote operator to control a Boston Dynamics Spot robot as if they were physically present — using immersive 360° video streaming and a VR-based control interface.

I led the development of the platform, focusing on the integration layer that bridges real-time video streaming with robot control, ensuring stable and low-latency operation for the remote user.

  • 360° Video Streaming – Implemented a real-time 360° video pipeline streamed from cameras mounted on Spot to a VR headset, giving the operator an immersive first-person view of the robot's environment.
  • VR Control Interface – Built a VR-based control interface allowing intuitive remote operation of Spot, translating head movements and controller inputs into robot commands via ROS.
  • Integration Layer – Designed and implemented the middleware connecting the video streaming pipeline with the robot control system, achieving synchronized perception–action feedback with minimal latency.
  • Cloud Infrastructure – Deployed supporting services on AWS to handle data logging, session management, and remote connectivity for operators outside the local network.

The platform demonstrated that immersive telepresence for quadruped robots is achievable with consumer-grade VR hardware, opening up use cases in remote inspection, hazardous environments, and assistive robotics.
