Representation Learning in Decentralised Multi-Agent Systems

  • Technologies Used: Python, PyTorch, SimCLR, Distributed Learning
  • Institution: Imperial College London
  • Project date: 2023 – 2024
  • Type: MEng Final Year Thesis

Project Details

This thesis explored how multiple autonomous agents can collaboratively learn useful data representations without a central coordinator — a challenging setting where agents hold different, non-identically distributed (non-IID) data.

The core contribution was a decentralised multi-agent adaptation of SimCLR, a self-supervised contrastive learning framework. Rather than sharing raw data or labels, agents exchange learned model parameters and iteratively refine their representations through a diffusion-based consensus mechanism.

  • Decentralised SimCLR framework – Designed and implemented a multi-agent contrastive learning system where agents collaboratively learn representations purely from unlabelled data, without any central server or shared dataset.
  • Non-IID robustness – Evaluated how heterogeneous data distributions across agents affect representation quality, and showed that collaborative learning improves generalisation over single-agent baselines even under severe data skew.
  • Diffusion methods analysis – Performed a comparative analysis of Exact Diffusion versus classical diffusion (gossip averaging), evaluating convergence speed and stability in distributed settings across varying network topologies.

The results demonstrated that decentralised representation learning is a viable and robust approach, with the framework outperforming large single-agent models in generalisation across held-out tasks. This work contributes to the growing field of federated and decentralised machine learning.
